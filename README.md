PowerShell GUI Builder

Building WinForms applications in PowerShell often requires writing hundreds of lines of repetitive code.
PowerShell GUI Builder provides a visual designer that allows administrators and developers to focus on functionality rather than UI boilerplate.

A drag-and-drop WinForms designer for PowerShell that lets you visually build Windows applications and export them as standalone PowerShell scripts.

Features
*Drag-and-drop control placement
*Multi-page applications using designer tabs
*Automatic WinForms code generation
*Real-time PowerShell code preview
*Save and load projects (.psgui.json)
*Export standalone PowerShell scripts (.ps1)
*Button actions and tab navigation
*Visual property editing
*DataGridView, ComboBox, ListBox and data source support
